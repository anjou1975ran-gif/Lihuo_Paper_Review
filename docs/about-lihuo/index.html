關於理火

理火是一套生成治理與證據邊界框架。它不以格式、權威、自信或自我宣告取代可核對的證據、責任位置與失效條件。

邏輯

一句話為何成立、成立到哪裡，以及何時必須停止成立。

責任

誰提出、誰生成、誰批准、誰使用、誰覆寫，以及誰承擔後果。

誠實

不知道不表演知道；未完成不宣稱完成；未部署不冒充已上線。
